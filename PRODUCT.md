# Product

## Register

product

## Users

Graal server staff and developers who administer servers, inspect live activity, manage scripts/files/NPCs and troubleshoot content from a Windows desktop.

## Product Purpose

GoRC is a focused desktop control surface for Graal RemoteControl servers. It should make technical administration fast to understand and safe to operate, with the most important session state visible without forcing the user through configuration screens.

## Brand Personality

Technical, fast, easy to use. The visual direction is a modern minimalist desktop app, combining VS Code's developer-tool clarity with restrained gamer/programmer details and Discord's approachable simplicity.

## Anti-references

Avoid dense legacy-admin styling, decorative gamer neon, oversized gradients, noisy dashboard cards, unexplained icon-only controls, and UI that hides connection or sync state behind hover-only interactions.

## Design Principles

- Keep the task surface quiet and information-dense without making it intimidating.
- Make live connection, player count, sync state and pending conflicts visible at a glance.
- Prefer familiar developer-tool patterns over novel interaction models.
- Use accent color for state and action feedback, not decoration.
- Let progressive disclosure reduce clutter while preserving discoverability with labels, tooltips and clear active states.

## Accessibility & Inclusion

Maintain keyboard-accessible controls, visible focus states, descriptive labels/tooltips for icon-only actions, sufficient contrast for chat and status text, and reduced-motion fallbacks for transitions.
