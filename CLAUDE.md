# GoRC

## Branches: perguntar antes de começar

Este projeto tem dois clientes, cada um na sua branch:

| Branch | Para qual servidor |
|---|---|
| `main` | Graal original |
| `alpaxis` | Alpaxis |

**No início de toda sessão nova, pergunte em qual das duas o trabalho deve ser feito**, antes de editar arquivos ou fazer commit. Pergunte mesmo que a branch atual ou o pedido pareçam indicar a resposta.

- O que é do Alpaxis fica só na `alpaxis` e não entra na `main`.
- A `alpaxis` costuma estar em uma worktree, em `.claude/worktrees/alpaxis`.
- Cliente de referência do Alpaxis (somente leitura): `Z:\Projetos\Alpaxis.RemoteControl`.
